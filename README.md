# Baltimore Scanner

Live Police, Fire & EMS radio scanner for Baltimore City with real-time speech-to-text transcription.

## Features

- **Live Audio Stream** - Embedded Broadcastify player (Feed ID: 40593)
- **Speech-to-Text** - Real-time transcription using Web Speech API
- **Timestamped Transcript** - Each entry shows when it was captured
- **Responsive Design** - Works on desktop and mobile

## Usage

1. Open `index.html` in a modern browser (Chrome, Edge, or Safari recommended)
2. Click play in the Broadcastify player to start the audio stream
3. Click "Start Transcription" to begin speech-to-text
4. Allow microphone access when prompted
5. Play audio through speakers so your microphone can capture it
